# Vendored reference data

Both files in this directory are **derived from the publishers' own
releases** by `app/eval/vendor.py`, which is committed beside them so the
derivation is reproducible. Nothing here is hand-written: an approximate
technique list would make every hallucination rate this project reports a
fiction, which is worse than reporting none.

Regenerate with `python -m app.eval.vendor`.

## mitre_attack_enterprise.json

- **Catalogue**: MITRE ATT&CK Enterprise
- **Version**: 17.1
- **Contents**: 823 techniques
- **Source**: https://raw.githubusercontent.com/mitre-attack/attack-stix-data/master/enterprise-attack/enterprise-attack-17.1.json
- **SHA-256 of the download**: `0d1c347a4d584cf7e11ef46556c33b7689341443bf86299188d46c307274323b`
- **Retrieved**: 2026-08-10
- **Derivation**: attack-pattern objects, projected to their mitre-attack external_id and name. Generated by app/eval/vendor.py.
- **Licence / attribution**: MITRE ATT&CK® is © The MITRE Corporation. Used under the ATT&CK Terms of Use: https://attack.mitre.org/resources/legal-and-branding/terms-of-use/

## cwe.json

- **Catalogue**: MITRE CWE
- **Version**: 4.20
- **Contents**: 969 weaknesses
- **Source**: https://cwe.mitre.org/data/xml/cwec_latest.xml.zip
- **SHA-256 of the download**: `3976f599e5e5200219a3108bb896d06e2a88fbb293369e1883cb423a5e9d7d50`
- **Retrieved**: 2026-08-10
- **Derivation**: Weakness elements, projected to CWE-<ID>, Name, Status and Abstraction. Generated by app/eval/vendor.py.
- **Licence / attribution**: CWE™ is © The MITRE Corporation. Used under the CWE Terms of Use: https://cwe.mitre.org/about/termsofuse.html

Deprecated and revoked entries are retained and flagged rather than
removed. A model naming a technique ATT&CK has since retired did not
invent it, and scoring that as a fabrication would make the hallucination
rate drift upward with the calendar instead of with model behaviour.
